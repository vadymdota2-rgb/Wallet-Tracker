# TwemojiCountryFlags.woff2

Шрифт только с флагами стран. Приложение подключает его там, где система
не рисует флаги-эмодзи (Windows и браузеры на Chromium показывают вместо
🇺🇸 буквы «US») — см. `src/lib/flags.ts`.

Файл взят без изменений из пакета `country-flag-emoji-polyfill` 0.1.10
(TalkJS, https://github.com/talkjs/country-flag-emoji-polyfill).

Рисунки флагов — Twemoji, © Twitter, Inc. и другие участники,
лицензия CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/),
https://github.com/twitter/twemoji. Изменений рисунков нет. Источник
назван в приложении: «Конфиденциальность и условия» → внизу.
